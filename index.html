Case study · Enterprise knowledge assistant

Custom RAG chatbot for an organisation knowledge base

Teams spent hours to find answers in wikis, shared drives, PDFs and tickets. Some information was duplicated or out of date. I designed and built a private AI assistant. It answers from the organisation's own content and shows the source of each answer.

What I built

  • Ingestion: Connectors collect documents, wikis, PDFs and FAQs. The pipeline cleans the content, removes duplicates and syncs each change.
  • Retrieval: The system splits content by structure and stores embeddings in a vector database. Hybrid search and re-ranking find the most relevant text.
  • Grounded answers: Each answer shows its source documents. When the assistant does not know the answer, it says so.
  • Access control: Users get answers only from content that they have permission to see.
  • Private hosting: The models run in the organisation's cloud. Data does not leave the organisation.
  • Quality: A test set of real questions measures accuracy. Users give feedback in the chat. Monitoring tracks accuracy, latency and cost.
